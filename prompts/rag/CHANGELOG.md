# RAG Prompt Changelog (HW2 — Крок 3 «RAG з джерелами»)

Версіоновані промпти генерації відповідей із цитуванням джерел для `src/hw2/rag.py`.
Кожна версія містить `system.txt` (незмінні правила на початку для prompt caching) та `user_template.txt` (динамічний контекст і запитання в кінці проти ефекту *lost in the middle*).

## v2 — 2026-11-16 (Production Default)

- **Ізоляція джерел та захист від Indirect Prompt Injection (`OWASP LLM01`):** фрагменти документів обгорнуто в `<context>...</context>`, запитання — у `<question>...</question>`, із прямою забороною виконувати будь-які інструкції всередині тексту чанків.
- **Обов'язкове по-твердженневе цитування (`claims` → `answer`):** кожне твердження повинно мати непорожній `source_ids` виключно зі списку `{{allowed_source_ids}}`, а синтезований `answer` зобов'язаний вказувати `[Si] (документ — розділ)`.
- **Жорстка дисципліна «не знаю» (`abstained = true`):** деталізовано відмову для питань-пасток (коли ретрівер повернув суміжні чанки про інший звіт/метрику, але прямої відповіді немає) — стандартна фраза `«У наданих документах цієї інформації немає.»` та `claims = []`.
- **Контроль версій (`is_latest`):** заборонено подавати застарілі редакції (`is_latest=false`, наприклад архівні `v1.0`) як чинні правила, якщо користувач питає про діючий стандарт.
- **Відсутність витоку тестсету (No Golden Leakage):** у промпті немає жодних захардкоджених доменних цифр або відповідей із eval-набору (ураховано фідбек куратора з HW1).

## v1 — 2026-11-16 (Baseline)

- Базовий zero-shot промпт українською мовою для генерації JSON-відповіді з масивом `claims` та посиланнями `[S1]..[Sk]`.
- Без XML-ізоляції `<context>`, без явного переліку `allowed_source_ids`, без правил розмежування `is_latest=true/false` та без захисту від prompt injection у тексті документів.
